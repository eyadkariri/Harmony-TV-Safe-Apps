# Harmony-TV-Safe-Apps
Harmony TV Safe Apps is a clean, 100% safe open-source guide to sideload APKs on Huawei TVs without rooting or breaking system security. Unlock your smart screen's full potential safely using official developer methods tailored strictly for TV navigation.

### 📥 Installation & Setup Guide

1. **Download Arora Store:**
   * Download and install the **Arora Store** client on your device.

2. **Verify App Compatibility:**
   * Make sure that restricted apps (such as **Google Play Services**) are **not running** or installed on your system before proceeding.
